2. Бреши безопасности (оранжевая зона) 🟠
#	Проблема	Риск	Приоритет	Решение
1	Admin TOTP 2FA отсутствует	Админка защищена только паролем demo123456. При компрометации admin@mail.ru — полный контроль	🔴	QR-код + Google Authenticator (этап 35+ в плане)
2	CSRF double-submit token	SameSite=Lax не защищает от same-site атак (поддомены, open redirect). API на отдельном домене = критично	🔴	Вынести API на api.swiftmatch.app, внедрить double-submit cookie
3	Привязка сессии к устройству/IP	Refresh-токен можно использовать с любого устройства после кражи	🟡	Добавить fingerprint (user-agent + IP hash) в refresh_tokens
4	Stripe webhook без circuit breaker	При недоступности Stripe очередь webhook'ов может бесконечно расти	🟡	Добавить exponential backoff + dead-letter queue
5	Sentry в проде	DSN не заполнен → ошибки не мониторятся	🟡	Вписать DSN до релиза
3. Инфраструктурные риски (жёлтая зона) 🟡
#	Проблема	Риск	Решение
1	VPS не поднят	Нет staging-окружения для финального E2E с реальными ключами	Развернуть VPS → GitHub secrets → deploy
2	Redis на проде не протестирован	REDIS_URL задан локально, но под нагрузкой fallback не проверен	k6 100 VU на staging + сценарий ECONNREFUSED
3	Docker Compose не запускался	YAML валиден, но реальный подъём на VPS не проверен	Запустить на staging, проверить healthcheck/volumes/сеть
4	Windows-центричность	Скрипты .bat/.ps1 не адаптированы для Linux VPS	Переписать бэкапы и запуск под bash (или использовать Docker)
5	Внешний мониторинг отсутствует	Если VPS умрёт — никто не узнает	UptimeRobot + Grafana alerts в Telegram/Slack
6	Log aggregation нет	Логи на диске, без централизованного сбора	Loki/ELK после релиза
7	SSL Let's Encrypt auto-renewal	В nginx.conf есть SSL, но автообновление не настроено	certbot + cron
4. Слепые зоны тестов (жёлтая зона) 🟡
#	Сценарий	Статус	Что делать
1	Redis fallback (ECONNREFUSED)	❌	Интеграционный тест: отключить Redis → приложение живёт
2	Refresh race (два окна)	❌	E2E: два браузера одного юзера → быстрый refresh в обоих
3	Cookie edge cases	❌	Истекшая cookie mid-session, revoked refresh, concurrent tabs
4	File upload security	❌	15MB → 413, .php.jpg → 400, ../../etc/passwd → uuid
5	Rate-limit spec	❌	61-й запрос к логину → 429
6	WS reconnect + backoff	❌	Эмуляция обрыва мобильного интернета
7	GDPR full erasure cascade	❌	Юзер → активность → erase → 404 везде
8	Stripe webhook security	❌	invalid signature → 400, replay → idempotency
9	RevenueCat webhook	❌	E2E с моком событий
10	i18n completeness	❌	Все t("...") есть в RU и EN
11	Backup/restore smoke	❌	Restore → smoke-тесты в CI
12	IAP sandbox-тест	❌	После публикации в Google Play
