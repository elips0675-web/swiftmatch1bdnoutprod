🚀 Зоны роста и рекомендации
Несмотря на высокое качество, есть несколько моментов, которые можно улучшить для выхода на уровень "Enterprise Production":
1. Автоматизация Pre-flight Checklist
Вместо того чтобы полагаться на AI или разработчика для ручного запуска grep или проверки портов, добавьте эти проверки в CI/CD или pre-commit хуки:
Добавьте скрипт npm run check:ports, который парсит vite.config.ts и server/.env и сверяет порт 3002.
Добавьте lint-staged правило для поиска хардкодных строк (кроме разрешённых файлов) или console.log в server/src/.
2. Закрытие пробелов в E2E-тестах
В context.txt указано, что новые фичи (Ghost Mode, GDPR consent/erase, AI Icebreakers, A/B тесты) не покрыты Playwright.
Рекомендация: Создайте отдельный файл e2e/new-features.spec.ts и добавьте туда хотя бы по 1 критическому сценарию на каждую фичу (например: "Включение инкогнито → проверка, что профиль не виден в поиске под другим аккаунтом").
3. Исправление pre-existing тестов
6 падающих тестов фронтенда из-за localStorage в Node 25/jsdom.
Рекомендация: Выделите 1-2 часа на написание правильного мока для localStorage в src/test/setup.ts (например, через Object.defineProperty(global, 'localStorage', { value: { ... } })), чтобы достичь заветных 100% (179/179). Это повысит доверие к CI.
4. Управление размером AGENTS.md
Файл уже очень большой. Если в будущем вы начнёте использовать модели с меньшим контекстным окном, это может стать проблемой.
Рекомендация: Если файл превысит ~1500 строк, разделите его на:
AGENTS-RULES.md (Core Rules, Stack, Response Format)
AGENTS-PITFALLS.md (История ошибок и специфичные ограничения)
AGENTS-CHECKLISTS.md (Pre-flight, Security, Deployment)
5. Уточнение по Stripe Webhook
В документации указано: express.raw({ type: 'application/json' }) ДО express.json(). Это абсолютно верно для Stripe.
Рекомендация: Убедитесь, что в server/src/index.js этот middleware применён только к роуту /api/webhooks/stripe (или аналогичному), а не глобально ко всему приложению, иначе это сломает парсинг обычных JSON-запросов с фронтенда.
