## 📌 Правила для будущих этапов (из этапа 18)

- **Express: middleware порядка** — Sentry errorHandler обязан стоять ДО финального 500-хендлера, requestHandler — до роутов
- **Миграции** — только через `database/migrations/` + idempotent (information_schema + PREPARE, MySQL 8.4)
- **`migrate.js` не запускается из `server/`** — модуль в `database/migrations/`, mysql2 резолвится оттуда; применяли SQL напрямую + `INSERT INTO _migrations`
- **Пустые catch** — обязателен комментарий (линт no-empty)
- **`any`** — warn (решение этапа 17), новые ошибки lint не вносить
