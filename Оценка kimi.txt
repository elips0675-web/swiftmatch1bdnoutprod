Оценка SwiftMatch — 8.5 / 10 (технически) | 6.5 / 10 (к продакшену)
Общий вердикт
Проект находится в состоянии «готов к staging и закрытой бете, но не готов к открытому релизу без разблокировки внешних зависимостей». Кодовая база зрелая, тестовое покрытие выше среднего по индустрии, безопасность продумана многослойно. Основные риски — не код, а отсутствие реального окружения (VPS, ключи API, домен, SSL) и непрогнанная инфраструктура под нагрузкой.

Что сделано исключительно хорошо
Итеративный аудит-цикл — этапы 30–59 с закрытием находок трёх разных моделей (kimi/qwen/дипсик). Это редкая дисциплина: не просто «написал фичу», а «проверил, что аудит не найдёт регресс».
Graceful degradation — сервер стартует и живёт без всех внешних ключей (mock/fallback/skip + warn). Это спасает dev-окружение и снижает риск падения в проде при временной недоступности Redis/S3.
Схемная дисциплина — schema-validate.mjs в CI, EXPLAIN-аудит SQL, миграции идемпотентны, mysql_schema.sql синхронизирован с живой БД. Это убивает класс багов «колонка есть в коде, но нет в БД».
Security headers + blind spots — 7 тестов заголовков против живого сервера, E2E на refresh race и GDPR cascade, ratelimit spec (61-й запрос → 429).
Приоритет следующих шагов (фазы qwen, консенсус)
Фаза 1: «Первый рубль» (1–2 недели)
Staging VPS + GitHub secrets (DEPLOY_HOST, DEPLOY_USER, DEPLOY_SSH_KEY).
Заполнить реальные ключи (Stripe test, SMTP, Sentry DSN).
E2E на staging с реальными ключами.
docker compose up end-to-end + healthcheck/volumes/сеть.
Фаза 2: «Мобильный релиз» (2–3 недели)
Домен + SSL (Let's Encrypt auto-renewal).
Keystore + AAB + App Links (assetlinks.json + SHA256).
RevenueCat проект + ключ.
Google Play: политика 17+, скриншоты, TestFlight/Internal Testing.
Фаза 3: «Надёжность» (параллельно)
k6 100 VU на staging с мониторингом free -m / Threads_connected.
UptimeRobot + Grafana alerts в Telegram (CPU, 5xx, DB connections).
Тест плана отката (docs/rollback-plan.md).
Разбить AGENTS.md при превышении 1500 строк (сейчас ~1180, но растёт).
Фаза 4: «Масштабирование» (после релиза)
S3/CDN для фото.
FCM push на Android.
Twilio SMS + Rekognition/OpenAI фото-модерация.
Storybook / Design System.
Итог
Код готов на 85–90%. Не нужен новый продуктовый код. Нужно разблокировать прод: staging → ключи → домен → релиз Android. Технический долг второй очереди (CSRF double-submit, fingerprinting, circuit breaker, log aggregation) — после первых реальных пользователей, не раньше.
Если завтра появится VPS + домен + ключи — проект можно вывести в закрытую бету за 2 недели.
