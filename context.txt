# SwiftMatch — Production Context

## Stack
- **Frontend:** React 18 + Vite 8 + TypeScript 5 strict + Tailwind CSS 3 + shadcn/ui
- **Backend:** Express.js 4 + MySQL (mysql2) + Socket.IO 4
- **State:** TanStack Query 5 + React Context
- **Forms:** React Hook Form + Zod 4
- **Auth:** JWT (Bearer) + refresh tokens, dev-login для админки
- **Payments:** Stripe (mock-fallback без ключа)
- **Realtime:** Socket.IO (chats, online status, typing indicator)
- **Monitoring:** Sentry (установлен, ждёт DSN)
- **Logging:** Winston (JSON-формат)
- **i18n:** Custom LanguageContext (RU/EN)
- **Mobile:** Capacitor (Android APK), AdMob v6.0.0

## Ports
- Frontend: **8081** (Vite dev server, proxy → localhost:3002)
- API: **3002** (Express)
- DB: 3306 (MySQL via Laragon)

## Auth
- `adminAuth` middleware — **passive** (вызывает `next()` на ошибке, не блокирует)
- AdminGuard при отсутствии Supabase делает dev-login
- CORS — `*` (для Capacitor)

## Что сделано

### Платежи + Коммуникации
- **Stripe:** Idempotency-Key middleware, STRIPE_LIVE флаг
- **SMTP:** Nodemailer + retry (3 попытки, exponential backoff), graceful skip без ключа
- **Sentry:** `@sentry/react` + `@sentry/node`, beforeSend с PII scrubbing, requestHandler/errorHandler

### Инфраструктура
- **Docker:** `.dockerignore`, healthcheck (curl /health), `mem_limit: 512m`, `JWT_SECRET` через env
- **Nginx:** rate limit (api 30r/s, auth 5r/s), WebSocket 86400s, SSL, SPA fallback
- **CI/CD:** `.github/workflows/deploy.yml` — lint → build → test (MySQL сервис)
- **Миграции БД:** `database/migrations/` — нумерованные .sql + migrate.js
- **MySQL backup:** `scripts/backup-mysql.ps1` + `.sh`, retention 7 дней
- **Setup:** `scripts/setup.ps1` — авто-копирование .env + генерация JWT_SECRET + npm install
- **S3 scaffold:** lazy-init (AWS env → multer-s3, иначе локальный диск)
- **Redis scaffold:** lazy singleton с ioredis, disconnectRedis(), winston-логи
