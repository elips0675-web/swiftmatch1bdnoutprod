# SwiftMatch — Production Context

## Stack
- **Frontend:** React 18 + Vite 8 + TypeScript 5 strict + Tailwind CSS 3 + shadcn/ui
- **Backend:** Express.js 4 + MySQL (mysql2) + Socket.IO 4
- **State:** TanStack Query 5 + React Context
- **Forms:** React Hook Form + Zod 4
- **Auth:** JWT (Bearer) + refresh tokens, dev-login для админки
- **Payments:** Stripe (mock-fallback без ключа)
- **Realtime:** Socket.IO (chats, online status, typing indicator)
- **Monitoring:** Sentry (установлен, ждёт DSN)
- **Logging:** Winston (JSON-формат)
- **i18n:** Custom LanguageContext (RU/EN)

## Ports
- Frontend: **8081** (Vite dev server, proxy → localhost:3002)
- API: **3002** (Express)
- DB: 3306 (MySQL via Laragon)

## Auth
- `adminAuth` middleware — **passive** (вызывает `next()` на ошибке, не блокирует)
- AdminGuard при отсутствии Supabase делает dev-login
- CORS — `*` (для Capacitor)

## Что сделано (все 3 недели)

### Неделя 2 — Платежи + Коммуникации ✅
- **Stripe:** Idempotency-Key middleware (`server/src/middleware/idempotency.js`), STRIPE_LIVE флаг (при `true` mock отключается, без ключа → 500)
- **SMTP:** Retry-логика (3 попытки, exponential backoff 1s/2s/3s), проверка пустых SMTP_USER/PASS → graceful skip
- **Sentry:** Установлены `@sentry/react` + `@sentry/node`, init с `beforeSend` (PII scrubbing: email, токены, IP). `server/src/sentry.js` — requestHandler/errorHandler для Express. `src/lib/sentry.ts` — клиентский init.
- **noValidate:** Добавлен на login.tsx, register.tsx, forgot-password.tsx, reset-password.tsx

### Неделя 3 — Инфраструктура ✅
- **MIME-фильтр:** `file.mimetype.startsWith('image/')` + расширение .jpg/.jpeg/.png/.gif/.webp
- **S3 scaffold:** lazy-init — при AWS_* env → `@aws-sdk/client-s3` + `multer-s3`, иначе локальный диск (`server/uploads/`)
- **Redis scaffold:** `server/src/redis.js` — lazy singleton с `ioredis`, ждёт REDIS_URL
- **Миграции БД:** `database/migrations/` — нумерованные .sql файлы + `migrate.js` (создаёт таблицу `_migrations`, применяет новые)

### Неделя 4 — Production Hardening ✅
- **Docker:** `.dockerignore` (node_modules, .git, .env, dist), `restart: unless-stopped` в docker-compose.yml
- **Nginx:** `nginx/swiftmatch.conf` — rate limit (api: 30r/s, auth: 5r/s), `client_max_body_size 20M`, WebSocket 86400s, SSL, SPA fallback
- **CI/CD:** `.github/workflows/deploy.yml` — lint → build → test (MySQL сервис)
- **AdMob:** динамический импорт `@capacitor-community/admob` с fallback на `setTimeout(3000)`
- **Winston:** `server/src/logger.js` переписан с `winston.createLogger`, JSON-формат с timestamp/level/msg/rid

### Дополнительно ✅
- **admin/analytics.js:** создан (overview, retention, revenue-mix, registrations) — убирает 404
- **/health роут:** `GET /health` — проверяет `SELECT 1` из БД
- **WebSocket heartbeat:** `pingInterval: 10000`, `pingTimeout: 5000` на сервере
- **WS reconnect:** `reconnectionAttempts: Infinity`, `reconnectionDelayMax: 30000`, `randomizationFactor: 0.5` на клиенте
- **Playwright:** webServer уже настроен (сервер + фронт)
- **README:** обновлён статус всех пунктов
